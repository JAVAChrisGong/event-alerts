# 重大事件提醒 · 股市日历

未来/历史重大金融事件 + 倒计时 + 提醒 + 事件详情（内容要点/利好利空/往期数据）+ 8 大指数 K 线（前后 60 天可缩放，MA5/10/20/60/240 + 成交量）。

## 访问

GitHub Pages 自动发布（每天 08:30 自动更新行情数据）：
https://<你的用户名>.github.io/event-alerts/

## 功能

- 未来视图：近一年国内外的重大会议与数据发布，倒计时到分钟级
- 历史视图：过去 6 年事件回顾（含已发生事件自动归档），点击查看二级页
- 二级页：会议内容要点 → 每条影响 → 利好/利空方向（具体板块）→ 往期数据对比 → 8 指数 K 线
- 8 指数：上证、创业板、沪深300、科创50、中证2000、纳斯达克、道琼斯、标普500
- K 线：±60 天窗口，滑块 30~360 根缩放，MA5/10/20/60/240，成交量

## 数据更新

每日 08:30 GitHub Actions 自动抓取行情（`tools/fetch_indices.js`），提交后 Pages 自动刷新。
手动触发：仓库 Actions 页面 → 更新行情数据 → Run workflow。

数据源：腾讯 / 新浪 / 中证指数官网。
